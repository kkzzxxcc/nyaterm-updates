# nyaterm-updates

Update distribution channel for a private fork of [nyakang/nyaterm](https://github.com/nyakang/nyaterm).

This repository contains **only build artifacts** (Windows x64 setup.exe / portable zip), update manifests, and the release workflow. The source code lives in a private mirror.

## Downloads

Latest release: https://github.com/kkzzxxcc/nyaterm-updates/releases/latest

The installed app auto-updates from the `channel` tag manifest.
